# Running Game Night Shelf

## How to Run

Use Node.js 22.12 or newer. Start in the `Game Night Shelf` folder.

### 1. Create the database

1. On Render, create a free Postgres database named `gamenightshelf`.
2. Create `server/.env` and fill in the values from the database's **Connections** section:

```sh
PGDATABASE=
PGHOST=
PGPASSWORD=
PGPORT=
PGUSER=
```

`.env` is listed in `.gitignore`, so the credentials are never committed.

### 2. Build the client

```sh
cd client
npm install
npm run build
```

### 3. Start the server

In a second terminal:

```sh
cd server
npm install
npm start
```

`npm start` runs `npm run reset` first, which drops and recreates the `games` table and seeds it with the six games. Then it starts the server. Open **http://localhost:3001** to use the app.

For the lab's development workflow, leave the server running and run `npm run dev` in the client terminal. Open the URL Vite prints (usually http://localhost:5173). Vite forwards `/games` requests to Express. Rebuild the client after changing a detail page or its scripts so Express serves the latest files.

### Checking the table with psql

Copy the **External Database URL** from Render's **Connect** menu and run `psql` followed by that URL. Then:

```sql
\d games
SELECT * FROM games;
```

Type `\q` to exit.

## Database Table

The `games` table has the following structure:

| Column      | Type         | Primary key |
| ----------- | ------------ | ----------- |
| id          | SERIAL       | ✅          |
| name        | VARCHAR(255) |             |
| category    | VARCHAR(255) |             |
| players     | VARCHAR(50)  |             |
| playtime    | VARCHAR(50)  |             |
| price       | VARCHAR(10)  |             |
| image       | VARCHAR(255) |             |
| description | TEXT         |             |
| submittedby | VARCHAR(255) |             |

PostgreSQL stores unquoted column names in lowercase, so the client reads `playtime` and `submittedby`.

## Connection to the Lab

This project follows UnEarthed Part 2. It uses a `pg` connection pool, `dotenv` for the database credentials, a reset script that creates and seeds the table, and a controller that queries it.

- `GET /games` returns every row in the `games` table as JSON, ordered by ID.
- `GET /games/:gameId` looks up the ID in the database and serves the detail HTML if the game exists.
- The detail script fetches the games and uses `find()` to select the requested game.
- Unknown game IDs and unmatched Express routes return a custom page with HTTP status 404.
- The Vite configuration builds the client into `server/public`, as in the lab.

The stylesheet is in `client/public` so the same URL works on the home, detail, and 404 pages. Pico CSS is included locally. Cover illustrations are static SVG image files, displayed with ordinary image elements. The project has no frontend framework.
