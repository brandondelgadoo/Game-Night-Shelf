# Running Game Night Shelf

## How to Run

Use Node.js 22.12 or newer. Start in the `Unit 1 Project` folder.

In one terminal, install and build the client:

```sh
cd client
npm install
npm run build
```

In a second terminal, install and start the server:

```sh
cd server
npm install
npm start
```

Open **http://localhost:3001** to use the built app, including its 404 responses.

For the lab's development workflow, leave the server running and run `npm run dev` in the client terminal. Open the URL Vite prints (usually http://localhost:5173). Vite forwards `/games` requests to Express. Rebuild the client after changing a detail page or its scripts so Express serves the latest files.

## Connection to the Lab

This project follows UnEarthed's client/server structure. It uses an Express router, a JavaScript data array, static HTML, `fetch()`, and DOM manipulation with `createElement()`, `textContent`, and `appendChild()`.

- `GET /games` returns the complete game array as JSON.
- `GET /games/:gameId` serves the detail HTML for an existing game.
- The detail script fetches the array and uses `find()` to select the requested game.
- Unknown game IDs and unmatched Express routes return a custom page with HTTP status 404.
- The Vite configuration builds the client into `server/public`, as in the lab.

The stylesheet is in `client/public` so the same URL works on the home, detail, and 404 pages. Pico CSS is included locally. Cover illustrations are static SVG image files, displayed with ordinary image elements. The project has no database or frontend framework.
